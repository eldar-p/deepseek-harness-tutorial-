# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in GIM CLI a harassment-free experience for everyone.

## Standards

**Encouraged:** respectful feedback, constructive criticism, focus on user safety and privacy.

**Unacceptable:** harassment, discrimination, publishing others' private information, trolling.

## Enforcement

Maintainers may remove or reject contributions that violate this code. Report issues to the repository owner via GitHub.
