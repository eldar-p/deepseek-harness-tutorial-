# CONTEXT RULES (Deep)

1. Disk is source of truth. Prefer Read/grep files over recalling.
2. Session inject = current dialog + tools only; last 5-10 messages + prior summary.
3. Tool stdout > 1000 lines: prune short note; write full log under workspace/logs/; do not paste raw dump into chat.
4. Project layout lives in STRUCTURE.txt — update it; never load the whole tree into context.
5. Preferences → .deep/memory.json only with user consent; never into logs.
6. Secrets never in prompts/logs/memory — use .env (gitignored); do not echo values.
7. KV/session are not archives — important facts → disk or memory.json.
8. Shell = guest container only (no host bash/pwsh).
9. No "Generated by Deep" watermarks in artifacts.
